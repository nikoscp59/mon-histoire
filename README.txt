MON HISTOIRE — site propre

1. Ouvre index.html dans Chrome ou Brave.
2. Le design est déjà inclus dans style.css.
3. Pour ajouter une vidéo plus tard, ajoute-la dans la liste "videos" de app.js.
4. Le fichier vidéo doit être placé dans le dossier videos.

IMPORTANT :
Cette version est un site local. Pour permettre aux visiteurs de regarder les vidéos sur Internet et pour avoir un vrai bouton d'ajout de vidéos depuis le site, il faudra ensuite mettre le site en ligne et ajouter un stockage/serveur.
